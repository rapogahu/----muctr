# Лабораторные работы по программной инженерии

### Лабораторная работа №1
1. Создайте ДВИ вашей работы на первой лабораторной работе по предмету Программирование
2. Создайте ДВИ следующего алгоритма: программа получает через поле ввода число, число удваивается, результат выводится на экран, если введен 0 вывыодится сообщение об этом.

### Лабораторная работа №2
Дополните диаграммы ДВИ созданные на прошлом занятии диаграммой последовательности (дедлайн до конца сегодняшнего занятия) и диаграммой деятельности (дедлайн следующее занятие). Все действия указанные на диаграмме последовательности должны быть на ДВИ. При необходимости добавить действия отсутствующие на ДВИ, создайте Версию 2 диаграммы вариантов использования. 

### Лабораторная работа №3
Дополнить комплект UML диаграмм созданных на первых лабораторных работах структурными диаграммами (диаграмма классов, модулей, развертывания и др) описывающих структуру для вашей модели (что реализует те действия которые вы  описали)

### Лабораторная работа №4
Один из созданных на первых трех лабораторных работах комплект  UML диаграмм перевести в нотацию  IDEF  прокоментировать перевод (почему выбраны конкретные нотации)

### Лабораторная работа №5
Серый Волк, Ниф-Ниф, Наф-Наф и Нуф-Нуф стали филателистами. Каждый из них собирает марки определённой тематики: один — флору, другой — спорт, третий — космос, а Волк — фауну. Вся компания собралась за столом в доме Волка. При этом: Волк сидит слева от Нафа.
Ниф — справа от того, кто собирает марки про космос.
Нуф сидит напротив Нафа и при этом совсем не интересуется спортивной тематикой.
Вопросы:
Можно ли определить, какие марки собирает каждый из четырёх героев?
